# Navigating Challenges in Evaluating Health AI for Impact

Slides for the Global Digital Health Forum session, Bangkok, December 2026 (J-PAL, APHRC, The Agency Fund).

- `index.html`: the deck in The Agency Fund style. Open it in a browser.
- `calibrate-style.html`: the same deck in the Calibrate talk style.
- `src/`: build scripts. They reuse slides from [Nudge-talk](https://github.com/dalmia/Nudge-talk) and [calibrate-ai-commons-talk](https://github.com/dalmia/calibrate-ai-commons-talk) and swap in Noora Health examples.
- `assets/`: logos and QR codes.
